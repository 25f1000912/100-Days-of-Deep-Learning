# 100 Days of Deep Learning

A journey of learning Deep Learning through building one small project every day.

I believe the best way to learn something is by building it. Instead of just reading theory or watching tutorials, this repository focuses on learning through practical implementation, experimentation and problem-solving.

The goal is to explore different areas of Deep Learning by building 100 small projects, understanding how things work behind the scenes and improving my skills one project at a time.

## About This Repository

This repository contains 100 hands-on Deep Learning projects implemented using **Python and PyTorch**.

Each project is designed to be simple, focused and easy to understand. Most projects will have a single Python file with the core implementation so that the concepts remain clear without unnecessary complexity.

The projects will cover both fundamental and advanced topics in Deep Learning.

## Tools & Technologies

- **Python:** Main programming language.
- **PyTorch:** Building, training and experimenting with neural networks.
- **NumPy:** Numerical operations and array manipulation.
- **Matplotlib:** Visualizing data, training progress and model results.
- **Torchvision:** Working with image datasets, transformations and pretrained models.
- **Hugging Face:** Exploring pretrained models and transformer-based applications.
- **Google Colab:** Cloud-based development and GPU access when needed.

## Concepts & Topics Covered

### 1. Neural Networks & Deep Learning Fundamentals
Understanding the building blocks of neural networks and how they learn.

- Perceptrons and Multi-Layer Perceptrons (MLPs)
- Activation Functions (ReLU, Sigmoid, Softmax, etc.)
- Forward Propagation and Backpropagation
- Loss Functions and Gradient Descent
- Optimizers (SGD, Adam, etc.)
- Weight Initialization
- Batch Normalization and Dropout
- Learning Rate and Model Training

### 2. Computer Vision
Building models that can understand and process images.

- Image Classification
- Convolutional Neural Networks (CNNs)
- Data Augmentation
- Transfer Learning and Fine-Tuning
- Popular Architectures (LeNet, AlexNet, VGG, ResNet, etc.)
- Autoencoders and Image Denoising
- Feature Maps and Grad-CAM
- Object and Face Recognition

### 3. Natural Language Processing (NLP)
Working with text data and building language-based models.

- Text Preprocessing and Tokenization
- Bag of Words and Word Embeddings
- Recurrent Neural Networks (RNNs)
- LSTM and GRU
- Sequence-to-Sequence Models
- Named Entity Recognition (NER)
- Sentiment Analysis
- Text Classification and Summarization

### 4. Transformers & Large Language Models
Exploring modern architectures used in today's language models.

- Attention Mechanism and Self-Attention
- Transformer Architecture
- BERT and GPT
- Sentence Transformers and Semantic Search
- Question Answering
- Text Generation
- Fine-Tuning Pretrained Models

### 5. Generative AI & Multimodal Learning
Exploring models that can generate and understand different types of content.

- Generative Models
- Neural Style Transfer
- Contrastive Learning
- Vision Transformers (ViT)
- CLIP and BLIP
- Image and Text Embeddings
- Visual Question Answering
- Multimodal AI

### 6. Audio & Speech Processing
Building models that can process, understand and generate audio.

- Speech-to-Text
- Text-to-Speech
- Audio Classification
- Speech Emotion Recognition
- Speaker Recognition and Diarization
- Audio Denoising
- Voice Cloning
- Music Generation
- Sound Event Detection

### 7. Real-Time AI Applications
Applying deep learning models to real-time inputs and practical use cases.

- Real-Time Face Recognition
- Gesture Recognition
- Pose Estimation
- Eye Tracking
- Sign Language Recognition
- Real-Time Audio Classification
- Live Speech Recognition
- Audio-Visual Applications

## Learning Approach

- Build one small project every day.
- Keep implementations simple and self-contained.
- Understand the concept before implementing it.
- Experiment with different models and techniques.
- Learn from mistakes and improve each implementation.
- Focus on practical understanding rather than just completing projects.

## Goal

The goal is not just to complete 100 projects. It is to develop a strong understanding of Deep Learning, become comfortable with PyTorch and gain practical experience in building AI models.

**100 Days. 100 Projects. One Step Closer to Mastering Deep Learning.**
